PROJECT OVERVIEW
================================================================================
InstructAI is a full-stack Learning Management System (LMS) with AI-powered
curriculum generation. Built with Laravel 12 (PHP 8.2) backend, React + Vite
frontend, and FastAPI microservice for AI features.

Target Users: Teachers create courses and manage classrooms; Students enroll
and learn through interactive lessons and quizzes with AI tutor support.
