Bugs found & fixed along the way

CourseBuilder blank-screened on every load. A useMemo sat after the skeleton early-return, so React threw “more hooks than during the previous render” the moment course data arrived — the page died on every open. Fixed by hoisting the hook above the return (commit 7bff48b).
Quiz editor crashed on any coding question. QuestionBlock used the langAvailability prop without declaring it — one coding question and the whole editor unmounted. One-line fix (commit 22b03e8).
Note: your local backend (port 8000) had died at some point during the night — I restarted it via Herd and it’s running now. No backend code was touched; the retheme is CSS/JSX-only, and none of the caching or query work was modified.
