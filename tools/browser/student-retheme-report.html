Bugs found & fixed during the campaign

Lesson text was broken in light mode. Lesson bodies rendered through Tailwind's prose-invert, which forces light text — unreadable on any light background. Replaced with theme-neutral .lesson-prose rules that inherit ink/cream correctly in both themes.
AI-tutor button overlapped the quiz Continue control (measured ~39×50 px collision). The floating button now lifts clear of the quiz navigation bar whenever a quiz is open.
Contradictory footer during quizzes. The focus-mode footer said "Content Locked" while a quiz was actively being taken. It now states the actual condition: "Pass this quiz to continue" / "Finish the lesson to continue".
AI-tutor error-toast spam. When the Python AI service is down, mounting a lesson fired stacked "Failed to load AI characters" toasts over the quiz header (twice — two tutor instances mount). Failure is now console-only; the tutor degrades silently. Also removed the pulsing glow halo behind the button — an AI-design tell.

Layout pass — composition redesigned, not just colors

After the skin pass, a full review flagged that the layouts were still the old AI-dashboard compositions. Every student page was restructured to real Apple patterns: large serif titles directly on the canvas (no boxed hero cards), iOS segmented controls instead of underlined tabs, grouped lists (rows inside one rounded container with hairline separators), a narrower reading column for lesson content, and compact purpose-built rails.
