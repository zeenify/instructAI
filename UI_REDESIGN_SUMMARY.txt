🎨 DESIGN PRINCIPLES APPLIED
─────────────────────────────────────────────────────────────────────────────
  ✅ Accessibility (CRITICAL)
     - 4.5:1 color contrast minimum
     - Visible 2px emerald focus rings
     - Full keyboard navigation
     - Semantic HTML with proper roles
     - Icon labels and aria-labels

  ✅ Interaction (CRITICAL)
     - 44x44px minimum touch targets
     - cursor-pointer on clickable elements
     - Hover feedback with smooth transitions
     - 150-300ms animation duration
     - Visible focus states

  ✅ Visual Hierarchy
     - Typography scale: 4xl → sm → xs
     - Color hierarchy: Primary (emerald) for actions
     - Consistent spacing (4/6/8 units)
     - Emphasis through icons and gradients

  ✅ Dark Mode Excellence
     - Deep slate-950 background
     - Soft white text (slate-100)
     - Subtle borders (slate-700/50)
     - Color overlays for depth
     - No harsh whites

  ✅ Performance
     - Transform/opacity only (GPU-accelerated)
     - Smooth 150-300ms transitions
     - No layout shift on hover
     - Efficient gradient usage
